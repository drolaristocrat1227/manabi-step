# まなびステップ（中2数学・第1段階）

## 使い方（PC）
`index.html` をダブルクリックすると、ブラウザで開きます。インストールは不要です。

## できること
- **実力チェック**：中2の内容から出題し、間違えた単元は中1の内容までさかのぼって確認する（約15〜25問）
- **学習の順番を自動で決める**：苦手な単元のうち、土台になる単元から順に「今日のおすすめ」を出す
- **練習**：1セット5問。問題はプログラムで自動生成し、答えも計算で出すため正解の誤りがなく、問題は毎回変わる
  - 間違えたら、ヒントを見てもう一度挑戦できる → それでも違えば答えと解説を表示
- **記録**：連続学習日数、正答率、学習時間、2週間のグラフ、スキルの伸び（実力チェック時 → 今）
- **保存・出力**：印刷／PDF保存、バックアップファイルの保存・復元

## 収録範囲（24スキル）
| 学年 | 単元 |
|---|---|
| 中1（さかのぼり用） | 正負の数、文字と式、一次方程式、比例と反比例 |
| 中2 | 式の計算、連立方程式、一次関数、確率 |

図形の単元（平行と合同、三角形と四角形）とデータの活用は、図を描く仕組みが必要なため次の段階で追加します。

## 安全面
- 課金：なし。外部のAIやサーバーは使わない
- 個人情報：ニックネームだけを使い、データはその端末のブラウザの中だけに保存する
- 通信：外部への通信を禁止する設定（CSP）を入れている
- 注意：ブラウザの「閲覧データを削除」をすると記録も消えるため、ときどきバックアップを保存してください

## ファイル構成
```
index.html        画面の土台
css/style.css     デザイン（スマホ向け、ダークモード対応、印刷用）
js/skills.js      問題の生成、ヒント、解説（スキルの追加はここ）
js/app.js         画面、実力チェック、記録、保存
sw.js             オフライン対応
manifest.json     ホーム画面に追加するための設定
```
