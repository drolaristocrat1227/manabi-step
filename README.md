# まなびステップ（小6算数・中2数学）

公開先：https://manabi-step.pages.dev/ （Cloudflare Pages）

## 公開の更新
`bash deploy.sh` で公開する（GitHubへのpushだけでは公開先に反映されない）。

## 使い方（PC）
`index.html` をダブルクリックすると、ブラウザで開きます。インストールは不要です。

## できること
- **実力チェック**：中2の内容から出題し、間違えた単元は中1の内容までさかのぼって確認する（約20〜30問）。終わったあとに、全問または間違えた問題だけの答えと解説を見られる
- **学習の順番を自動で決める**：苦手な単元のうち、土台になる単元から順に「今日のおすすめ」を出す
- **練習**：1セット5問。問題はプログラムで自動生成し、答えも計算で出すため正解の誤りがなく、問題は毎回変わる
  - 間違えたら、ヒントを見てもう一度挑戦できる → それでも違えば答えと解説を表示
- **目標の設定（第2段階）**：「学力アップ」「定期テスト」「高校受験」と、1日のセット数（1〜3）を選ぶ
  - 定期テスト：テストの日と範囲から逆算して毎日のメニューを作る。苦手ほど多くくり返し、最終日は総復習。関係する中1の苦手は、その単元の直前に1回はさむ
  - 高校受験：中1からの全範囲で苦手をなくしつつ、できる単元の総復習を混ぜる
  - 今日のメニューはその日の最初に決まり、終わったものにチェックが付く
- **総復習**：いろいろな単元から10問（単元マップ、今日のメニューから）
- **やる気の仕組み**：レベルと称号、バッジ20種、今日の目標達成の記録、今週と先週の比較
- **記録**：連続学習日数、正答率、学習時間、2週間のグラフ、スキルの伸び（実力チェック時 → 今）
- **練習プリント**：範囲（今日のメニュー／苦手な単元／単元を選ぶ／実力チェックで間違えた問題／その単元だけ）と問題数（5・10・20）を選んで印刷・PDF保存。問題・解答・解説はそれぞれ印刷するかを選べ、解答・解説は別ページになる。問題の下に途中式を書く余白がある
- **計算メモ**：問題画面の下半分に開く方眼の手書き欄（ペン・消しゴム・全部消す）。書いた内容は端末の外に出ず、次の問題で消える
- **保存・出力**：印刷／PDF保存、バックアップファイルの保存・復元
- **データの初期化**：「記録」画面のいちばん下の「その他」の中にある。誤操作を防ぐため、説明のあとに確認画面を2回はさむ

## 学年（コース）
最初の画面で学年を選ぶ。学年ごとに記録（ニックネーム・実力チェック・目標・バッジ）を別々のキーに保存する（中2：`manabi-step-v1`、小6：`manabi-step-e6-v1`）。「記録」→「学年を切りかえる」で切りかえられるので、きょうだいで1台を使うこともできる。バックアップファイルには学年が記録され、ちがう学年には復元できない。

### 小学6年・算数（23スキル、`js/skills-e6.js`）
| 学年 | 単元 |
|---|---|
| 小5（さかのぼり用） | 整数と分数（公倍数・公約数、約分、分数のたし算・ひき算）、小数のかけ算・わり算、割合・速さ・平均、面積 |
| 小6 | 対称な図形、文字と式、分数のかけ算・わり算（逆数・小数との計算）、比、拡大図と縮図、円の面積、角柱と円柱の体積、比例と反比例、並べ方と組み合わせ方、データの調べ方 |

目標は「学力アップ」「テスト対策（単元テスト・学期末テスト）」「中学準備」。分数の答えは約分した形を求め、約分できる答えには「もっと約分できるよ」と知らせる（不正解にはしない）。答えが整数のときは分母を空にしてよい。

### 中学2年・数学（37スキル、`js/skills.js`）
| 学年 | 単元 |
|---|---|
| 中1（さかのぼり用） | 正負の数、文字と式、一次方程式、比例と反比例 |
| 中2 | 式の計算、連立方程式、一次関数、図形の調べ方（平行と合同）、三角形と四角形、データの活用（四分位数・箱ひげ図）、確率 |

図形と箱ひげ図の図は、問題ごとにSVGで描く。角度などの数値と図の形を一致させている。
実力チェックは各単元の代表スキルだけを出題する（`diag: false` のスキルは出題しない）。全問正解なら20問、すべて「わからない」でも29問。

## 安全面
- 課金：なし。外部のAIやサーバーは使わない
- 個人情報：ニックネームだけを使い、データはその端末のブラウザの中だけに保存する
- 通信：外部への通信を禁止する設定（CSP）を入れている
- 注意：ブラウザの「閲覧データを削除」をすると記録も消えるため、ときどきバックアップを保存してください

## ファイル構成
```
index.html        画面の土台
css/style.css     デザイン（スマホ向け、ダークモード対応、印刷用）
js/skills.js      問題の生成、ヒント、解説（スキルの追加はここ）
js/app.js         画面、実力チェック、記録、保存
sw.js             オフライン対応
manifest.json     ホーム画面に追加するための設定
icon-*.png        アプリのアイコン（Android用・iPhone用）
```
